# 유어데이 검증 결과

현재 클라우드 인스턴스의 실제 PHP 8.3.35·Apache와 MariaDB 11.4 컨테이너에서 검증했습니다.

- 별도 신규 DB에서 공식 그누보드·영카트 CLI 설치와 샘플 초기화 성공. 재실행 시 설치·상품 보존 확인.
- 브라우저: 홈의 8개 상품 이미지, 카테고리 필터, 니트 검색, 상품 상세, M 사이즈 선택, 장바구니, 비회원 주문서, 관리자 로그인 통과. 브라우저 JavaScript 오류 없음.
- 개발용 무통장 주문 저장·완료 화면 확인. DB의 상품액 39,000원, 배송비 3,000원, 실입금 0원, 미수금 42,000원, 상태 `주문` 확인. 주문 메모에 자동검증용·배송 및 입금 금지 표시.
- 모바일 390px 화면에서 홈·상품 상세의 가로 넘침과 상세 설명 폭·상품명 높이를 검사하고 실제 화면 확인.
- HTTP 검사: 주요 경로 13개와 비공개 경로 9개 통과. `.env`, `.git`, 개발·설치 스크립트, DB 설정·SQL 백업·세션 경로의 공개 접근 차단 확인.
- 사용자 정의 PHP 11개 파일 문법 검사 및 Python 문법 검사 통과.
- 서비스를 중지한 후 저장된 시작 명령으로 재시작하고 HTTP 검사 재통과.
- 개발용 SQL 백업을 별도 DB에 복원하여 상품 8개, 사이즈 옵션 21개, 자동검증 주문 1개 보존 확인. 임시 검증 DB는 제거.

이 결과는 현재 인스턴스 검증입니다. 환경 설정의 install_script와 start_skill 초안을 저장했으며 환경 게시나 새 클라우드 작업에서의 복원은 수행하지 않았습니다.

실제 PG 승인·취소, 운영 도메인·HTTPS, 이메일 전송, 주소 검색의 외부 API, 실배송은 검증 범위에 포함하지 않았습니다. 현재는 샘플 상품과 개발용 무통장 문구를 사용하는 개발 사이트입니다.
